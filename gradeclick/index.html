Why the PC version

A full keyboard for a full bundle of scripts.

Hands stay on the keys.

A whole bundle of scripts on a phone keypad is slow work. On a PC you type a mark, press Tab, type the next, and press Save All at the end. Half marks like 7.5 go in as you write them.

Install

Ready in under a minute.

There is no installer. GradeClick runs straight from its folder, so it works on office PCs where you cannot install software.

  1. Download with the password

    You get GradeClick-Windows.zip in your Downloads folder.

  2. Extract the whole zip

    Right click it, choose Extract All, then Extract. Keep every file in that folder; the app needs all of them.

  3. Open grade_click.exe

    Windows may show the blue box on the right the first time. Click More info, then Run anyway. It appears for any app that does not come from the Microsoft Store.

  4. Sign in and pin it

    Use your usual email and password. While it is open, right click its icon in the taskbar and choose Pin to taskbar for next time.

Questions

Before you start.

Which login do I use?

The same email and password you use in the GradeClick phone app. College teachers and external evaluators both sign in here.

Does it work outside the campus?

Yes, it works anywhere with internet. Marks are saved straight to the college server when you press Save All, so you need to be online while you work.

Will it run on my computer?

Any 64 bit PC with Windows 10 or Windows 11. It does not need admin rights and nothing else has to be installed.

Windows says the app is not recognised.

That message shows for apps that are not sold through the Microsoft Store. Click More info and then Run anyway. You only do this once.

How do I update to a new version?

Download again from this page, extract it, and replace the old folder. Your marks live on the college server, not on the PC, so nothing is lost.
